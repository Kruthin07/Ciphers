What is the Vigenère Cipher?

The Vigenère Cipher is a polyalphabetic substitution cipher that uses a keyword to encrypt text. Different key letters shift the message letters by different amounts, unlike a single-shift Caesar cipher.

ENCRYPTIONC = (P + K) mod 26
DECRYPTIONP = (C − K + 26) mod 26

Security notes

Advantages

  • Simple to understand and implement
  • Uses multiple substitution alphabets
  • More varied than a Caesar cipher

Limitations

  • Repeating keys can be attacked statistically
  • Short keys are easier to analyze
  • Not suitable for modern secure communication
Educational use only. Vigenère is a historical cipher, not a modern security tool.
